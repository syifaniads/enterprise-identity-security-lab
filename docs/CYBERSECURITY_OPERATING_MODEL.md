# Cybersecurity Operating Model Case Study

The retained Team 5 spreadsheet models a mid-size cybersecurity organization and maps security teams to representative tools.

## Teams represented

- Cybersecurity leadership
- Security Operations Center (Detect & Respond)
- Application & Product Security
- Cloud Security
- Identity & Access Management
- Vulnerability Management / Red Team
- Governance, Risk & Compliance
- Security Engineering
- Enterprise Security

## Tool categories represented

The worksheet maps tools such as SIEM/XDR, WAF, DLP, GuardDuty, Zscaler, OWASP ZAP, Burp Suite, ProjectDiscovery, Postman, Veracode, Active Directory, Okta, SailPoint, Nessus/Tenable, ServiceNow, and endpoint/security management products to team use cases.

## Portfolio interpretation

This artifact demonstrates security-domain analysis and tooling awareness. It does **not** prove hands-on production operation of every named commercial product. The public portfolio therefore keeps it as a supporting case study rather than presenting the tool list as direct experience.
