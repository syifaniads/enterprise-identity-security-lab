# IAM Operations Planning Exercise

A retained July/August 2025 roster artifact assigns staff coverage across SSO, IGA, and PAM skill labels. `Syifani (All)` appears in multiple L1 night-shift slots.

This repository treats that artifact as an **operations-planning / shift-roster exercise**. It is useful for discussing support coverage, skill matrices, handover, and escalation, but it is **not represented as proof of employment, production on-call duty, or real customer incidents**.

## Engineering takeaways

A real IAM operations model would additionally define:

- L1/L2/L3 escalation boundaries;
- incident severity and SLA/SLO targets;
- privileged break-glass ownership;
- change windows;
- after-hours approval paths;
- identity-provider / IGA / PAM runbooks;
- shift handover template;
- audit trail for emergency access.
